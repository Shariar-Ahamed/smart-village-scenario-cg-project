<h2 align="center">🌅 Smart Village Riverside Animation (Computer Graphics)</h2>

<p align="center">
This project is an animated <b>Computer Graphics</b> scene representing a peaceful <b>Bangladeshi village riverside environment</b> using <b>OpenGL & GLUT</b>.
</p>

---

## 📌 Project Overview

This project presents a **Smart Village Simulation** using computer graphics. It visualizes a modern rural environment with smart infrastructure, eco-friendly elements, and digital connectivity.

The main goal is to demonstrate how technology can improve village life through a graphical representation.

---

## 🎯 Features

* 🌞 Animated sun rising effect
* ☁️ Moving clouds with smooth transition
* 🚤 Boat animation with sway and drift
* 🌊 River water with reflection animation
* 🎣 Fisherman with dynamic fishing rod movement
* 🏡 Village houses, trees, and environment design
* 🌿 Realistic rural scene visualization

---

## 🛠️ Technologies Used

* C / C++
* OpenGL / GLUT
* Computer Graphics Concepts

## 🚀 How to Run

1. Install a C++ compiler (MinGW / GCC)

2. Install OpenGL & GLUT

3. Compile the code:

```
g++ main.cpp -o program -lglut -lGLU -lGL
```

4. Run the program:

```
./program
```
